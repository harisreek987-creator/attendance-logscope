# Attendance Tracker
**Module III | Group Python mini-project**

A menu-driven student attendance management and analytics application. This Python implementation is the program version; a separate frontend version was developed later.

## Features
- Student and subject management
- Date-wise and subject-wise attendance marking
- Attendance percentage and status analysis
- Recovery-class and safe-absence calculators
- Student, subject, monthly and class reports
- At-risk and critical attendance alerts
- CSV export and JSON file persistence

## Python concepts
Lists, dictionaries, sets, tuples, comprehensions, nested data, strings, `datetime`, functions, validation, JSON, CSV and exception handling.

## Run
```bash
python attendance_tracker.py
```

Runtime data files are generated locally and excluded from version control.
